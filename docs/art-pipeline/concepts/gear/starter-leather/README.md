# Proposed starter leather gear

`starter-leather-front-back.jpg` is a proposed front-and-back modeling reference for a basic new-character leather kit. It is based on `docs/art-pipeline/concepts/mannequins/masculine-front.jpg` and was generated with the built-in GPT image tool. It is concept reference only; it does not represent a completed 3D or runtime asset.

The generation prompt specified the exact same masculine face, body, and proportions; a full-body, matched-scale front and back A-pose on a neutral warm-gray background; a plain, worn brown sleeveless leather jerkin with stitched panels, a short split hem, front laces, and a narrow belt; dark supple leather trousers; ankle boots; and the existing dark undersuit sleeves visible. It specified no extra armor or accessories, with matte painterly stylized game art.
