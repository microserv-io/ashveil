# Tauren mannequin concepts

Each sex has a front, back and right-side reference for Tripo multi-view input.
The right-side image faces left. Every view holds a matching relaxed stance with the
arms slightly separated and unobstructed shoulders so the resulting mesh can exercise
body-specific shoulder fittings.

These AI-generated images are concepts, not evidence of one consistent 3D surface.
The model has not been reconstructed or fitted yet; review the generated geometry for
agreement between views before accepting it into the body pipeline.
