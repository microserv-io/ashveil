# Ashveil public website

This directory builds the public documentation site, including the rendered game design
document. GDD and public-site edits and publication are standing-authorized and do not
require an additional approval step.

The playable browser build is separate. Development and review previews stay private on
the Tailnet; publishing a playable demo requires explicit later authorization. Website
deployment must exclude the playable world and legacy demo builds.

Preserve existing concept art when the gallery grows. Each addition should contribute a
new composition or scene; a zoom or crop of existing artwork is not new gallery content.
